NYC listings platform: shipped in one month with Claude Code

Result: 1,000+ listings, 6 agents using it, 3 to 5 hours saved per client search, phase 1 shipped in one month.

Problem

Off-market listings arrive scattered across emails, PDFs, docs, and spreadsheets. Agents spent hours digging through them for every client search.

What I built

A listings platform, built with Claude Code and no engineering hire, that:

  1. Ingests off-market listings and parses them from whatever format they arrive in.
  2. Puts them in one searchable database with map search.
  3. Gives agents and managers role-based access.

Before and after: the landlord email next to the parsed listing detail page, landlord name, email and phone blurred

Building and landlord pages from the app, landlord names and emails blurred

Stack

Claude Code, Next.js, TypeScript, Supabase, Mapbox, Vercel.

What broke and how I fixed it

My first approach used one AI prompt to parse a landlord's file. It misread the layout and created bogus listings. I dropped the prompt for that source and built a dedicated parser for it.
